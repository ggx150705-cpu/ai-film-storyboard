## 1. 万能基础框架（固定提示词框架）

**核心逻辑**：零散指令会让 AI 丢失关键需求；标准化的固定框架能让 AI 100% 接收有效信息，避免"只听了一半"。

**万能基础框架**（七要素，按序填充）：
```
人物身份 + 核心情绪 + 语速停顿规则 + 场景受众 + 配音文本 + 细节补充 + 音质要求
```

**错误示范**：`帮我配个音，文案是XXX，温柔一点`（信息不完整）

**正确示范**：
```
你是28岁的小红书职场博主，核心情绪是真诚的干货分享，语速中等，重点内容放慢，
适配短视频口播场景，受众是职场新人，配音文本：XXX，保留自然呼吸感，生成48KHz无损音质，无杂音。
```

## 2. 情绪指令替代"有感情朗读"

**核心逻辑**："有感情"是 AI 无法精准识别的模糊指令，必须明确**情绪类型 + 强度 + 适配场景**，AI 才能精准拿捏语气。

**错误示范**：`有感情地朗读这段文案`

**正确模板**（按场景选）：

| 场景 | 指令要点 |
|---|---|
| 治愈向 | 核心情绪是温柔共情，语气舒缓松弛，像在耳边轻声讲故事，无夸张起伏，给人安抚感 |
| 带货向 | 核心情绪是亢奋的安利感，语气有起伏，重点福利内容语气加重、节奏加快，带动听众情绪 |
| 干货向 | 核心情绪是平和笃定，语气沉稳，重点知识点加重语气，无多余情绪波动，传递专业感 |

## 3. 补充口语化细节指令（弱化AI规整感）

**核心逻辑**：完全字正腔圆、零瑕疵、零波动的都是 AI；真人说话有自然的呼吸感、语气词、轻微节奏变化。补充这些细节能大幅降低机械感。

**可直接复制的补充指令**：
```
· 保留自然的呼吸感，句尾可带轻微气音，不要全程音量完全一致
· 口语化表达，适配日常说话逻辑，避免播新闻式的规整感
· 可根据文本内容，加入自然的语气词，比如"嗯""哎""对吧"，不要过度
· 遇到转折内容，可加入轻微的思考停顿，还原真人说话的状态
```

## 4. 明确场景与受众，匹配表达语境

**核心逻辑**：不同场景、不同受众的说话逻辑天差地别，明确这两点，才能让 AI 语气完全适配使用环境，避免书面化违和感。

**正确模板**（按场景选）：
| 场景 | 指令要点 |
|---|---|
| 儿童故事 | 给3-6岁小朋友听的睡前故事，受众低龄儿童，语气温柔亲切，咬字清晰，节奏缓慢，角色区分明显，有亲和力 |
| 直播间带货 | 抖音直播间带货口播，受众下沉市场用户，语气接地气有感染力，节奏快，重点福利内容重复强调 |
| 毕设答辩 | 本科毕设答辩宣讲，受众高校导师，语气沉稳专业，逻辑清晰，节奏平稳，无多余口语化内容 |

## 5. 音质要求

- 生成 `48KHz` 无损音质、无杂音
- 角色声音风格细分（低沉磁性/神秘悬疑/热血激昂/悲伤压抑）见 `performance.md`
- 口型与台词状态（口型+语速+停顿公式）见 `performance.md`
