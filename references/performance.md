## 1. AI 微表情提示词

每种情绪拆成 10 种微表情，每种含明确的面部动作描述。用法：把具体动作描述直接嵌入提示词，如 `[角色]眼眶泛红，泪水在眼眶打转，眼神失焦，嘴唇微颤`。

### 哀（悲伤/委屈/崩溃）

| # | 表情 | 面部动作描述 |
|---|---|---|
| 01 | 哀伤泛红 | 眼眶泛红，泪水在眼眶打转，眼神失焦，嘴唇微颤 |
| 02 | 空洞麻木 | 眼神失焦，瞳孔放大，表情僵硬，嘴角平直，像被抽空了灵魂 |
| 03 | 泪水滑落 | 一滴眼泪从眼角滑下，鼻尖泛红，眼神向下，嘴角微微下垂 |
| 04 | 隐忍不哭 | 眼眶泛红但死死忍住，嘴唇抿紧，下巴肌肉紧绷，鼻翼微缩 |
| 05 | 低声啜泣 | 用手捂住嘴，眼泪挂在脸颊，鼻翼抽动，肩膀微微颤抖 |
| 06 | 绝望闭眼 | 双眼紧闭，眉头紧皱，嘴角下拉，仿佛放弃了所有希望 |
| 07 | 崩溃大哭 | 双眼紧闭，泪水大量涌出，嘴巴张开哭喊状，表情扭曲 |
| 08 | 默默流泪 | 不做任何表情，眼泪无声从眼角滑落，脸上没有多余表情 |
| 09 | 委屈撇嘴 | 下唇前伸，嘴唇嘟起，眉头微蹙，眼神躲闪，像要哭的样子 |
| 10 | 触景生情 | 眼神突然变得柔软，眼眶微湿，嘴角微微抽动，陷入回忆 |

### 惊（震惊/恐惧/害怕）

| # | 表情 | 面部动作描述 |
|---|---|---|
| 01 | 瞳孔放大 | 眼睛睁大，嘴巴微微张开，身体僵住 |
| 02 | 瞳孔地震 | 瞳孔剧烈收缩，嘴巴微张，面部瞬间僵硬 |
| 03 | 惊恐后退 | 眼神警惕，身体后倾，双手抬起护在胸前 |
| 04 | 战栗恐惧 | 眼睛充满恐惧，嘴巴张开但发不出声，身体像被定住 |
| 05 | 难以置信 | 眼睛睁大，眉毛上扬，嘴巴微张，头微微后仰 |
| 06 | 怀疑警惕 | 眼睛眯起，瞳孔收缩，头微微向后退，表情充满戒备 |
| 07 | 心虚躲闪 | 眼神飘忽，不敢直视，嘴角微微抽动，肩膀微缩 |
| 08 | 惊吓后怕 | 表情开始放松，嘴唇颤抖，手捂住胸口 |
| 09 | 毛骨悚然 | 眼睛半眯，瞳孔缩小，嘴唇微张，后背紧绷，表情凝固 |
| 10 | 绝望失神 | 双眼空洞涣散，眼皮无力下垂，嘴唇惨白微颤 |

## 2. AI 视频口型提示词（说话状态四宫格）

公式：**台词状态 = 口型 + 语速 + 停顿**

| 状态 | 口型 | 语速 | 停顿/细节 | 示例台词 |
|---|---|---|---|---|
| 轻声解释 | 嘴唇微张 | 放慢 | 眼神保持温和 | 其实是这样的… |
| 急切辩解 | 嘴巴快速开合 | 快 | 眉头抬起、呼吸变急 | 不是的！我真的没有！ |
| 咬字坚定 | 唇线清楚 | 中 | 下巴微抬、停顿后再说 | 我会完成这件事。 |
| 欲言又止 | 嘴唇张开又合上 | 慢 | 眼神躲开、沉默半秒 | 我…其实…算了。 |

| 悲伤压抑型 | 声音低落、语速缓慢、停顿多 | 情绪短片/离别剧情/回忆独白/悲伤角色 | 柔和悲伤声音、低落语气、语速缓慢、音量偏低、情绪停顿、脆弱克制的表达 | sad tone, melancholic voice, slow pace, soft volume, emotional pauses |

## 4. 表情描写提示词（8种）

> 基础表情的完整文字描写，直接嵌入提示词。写角色神态时调用。

| 表情 | 描写 |
|---|---|
| 微笑 | 轻轻微笑，嘴角上扬，眼神柔和明亮，面部放松，散发温暖亲近感 |
| 大笑 | 仰头大笑，嘴巴张开，露出牙齿，眼睛微微眯起，面部表情舒展，情绪明朗又热烈 |
| 苦笑 | 嘴角勉强上扬，笑容略显僵硬，眉眼透出无奈，眼神复杂，带着压抑情绪的苦笑 |
| 冷笑 | 嘴角微微一撇，露出淡淡冷笑，眼神冷淡疏离，面部紧绷，带着轻蔑和讥讽感 |
| 惊讶 | 睁大双眼，眉毛上扬，嘴巴微微张开，神情瞬间停住，表现出明显的惊讶情绪 |
| 震惊 | 瞳孔放大，眼睛睁圆，嘴巴微张，表情僵住，身体微微一顿，流露出强烈震惊感 |
| 疑惑 | 轻轻歪头，眉头微蹙，眼神带着不解，嘴唇轻抿，脸上浮现出明显的疑惑神情 |
| 委屈 | 嘴角下撇，眼眶微红，眉眼低垂，神情隐忍克制，带着想哭却强忍的委屈感 |
