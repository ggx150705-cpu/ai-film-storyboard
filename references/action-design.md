## 1. 拳法类（10招）

| 招式 | 特点 |
|---|---|
| 直拳 | 干脆、快速、正面压迫感 |
| 摆拳 | 力量感强，适合表现愤怒 |
| 勾拳 | 近身爆发，适合打出冲击感 |
| 连环拳 | 节奏快，压制对手 |
| 反手拳 | 有突然性，适合反击 |
| 重拳 | 动作幅度大，适合慢镜头 |
| 虚晃拳 | 假动作，制造紧张感 |
| 贴身短拳 | 巷战、室内打斗常用 |
| 双拳连击 | 英雄式压迫打法 |
| 低位击打 | 表现实战感、狼狈感 |

## 2. 棍棒类（10招）

| 招式 | 特点 |
|---|---|
| 起棍势 | 起手稳，便于衔接 |
| 横扫 | 范围攻击，打开空间 |
| 下劈 | 力量感强，正面压制 |
| 上挑 | 破防上扬，带出节奏 |
| 反手棍 | 突然反击，动作利落 |
| 双手重击 | 压迫感强，适合终结 |
| 架棍格挡 | 防守清晰，便于转进攻 |
| 棍尾反击 | 近身突变，高级感强 |
| 扫腿棍 | 打乱重心，适合放倒对手 |
| 转身棍击 | 动势完整，观赏性强 |

## 3. 防守 & 闪避类（18招）

**格挡类（8招）**：抬臂格挡 / 双臂护头（被压制防御感）/ 外拨格挡（利落专业）/ 内拨格挡（贴身反击）/ 交叉格挡（抗重击）/ 肘臂格挡（现代格斗感）/ 掌推格挡（武侠警匪通用）/ 武器格挡（刀棍盾牌常用）

**闪避类（10招）**：后撤步（拉开距离）/ 侧闪（干净专业）/ 下潜闪避（拳击感）/ 低头躲拳（紧张感）/ 转身闪避（动作好看）/ 滑步闪避（灵活高手感）/ 翻滚闪避（影视感强）/ 后仰闪避（子弹时间、慢镜头）/ 蹲身避开（巷战近身战）/ 借物闪避（躲到柱子、桌子、车后）

## 4. 12个万能打斗提示词模板

通用结构：**招式名（含别称）+ 画面描述 + 核心关键词**。直接套用或替换 [人物] 占位。

示例模板：

**① 极速瞬身突袭**（别称：残影突进、瞬杀近身）
- 画面描述：`[人物]施展极速瞬身突袭，身形骤然虚化，带出多重流动残影，瞬间拉近与对手距离，身体前倾蓄力，姿态凌厉迅猛，气流紊乱飘动，衣袂翻飞，战场背景简洁大气，国风漫剧质感，动态张力拉满，超清细节`
- 核心关键词：瞬身、突进残影、高速移动、近身突袭、气流扰动、动态模糊、凌厉打斗

**② 凌空飞踢**（别称：腾空踹击、凌空制敌）
- 画面描述：`[人物]施展凌空飞踢，双脚腾空跃起，身体舒展悬空，单腿蓄力向前猛踹，身姿挺拔有力，裙摆衣料随动作剧烈飘动，空中带有轻微气流光影，旷野战场为背景，动作流畅帅气，漫剧高清画质`
- 核心关键词：腾空、飞踢、凌空动作、蓄力攻击、空中打斗、动态肢体、飘逸身姿

**③ 反手格挡防御**（别称：卸力格挡、侧身防御）
- 画面描述：`[人物]施展反手格挡防御，手臂快速横挡身前，侧身卸力稳住身形，身体紧绷蓄力，姿态沉稳稳健，抵挡敌方攻势，周身气流轻微震荡，画面攻防感十足，国风漫剧光影，细节清晰`
- 核心关键词：格挡、防御、侧身卸力、稳身、防守姿态、攻防对抗、肢体紧绷

> 更多招式可组合使用（如"极速瞬身突袭 → 凌空飞踢 → 反手格挡"构成攻防回合），分镜时按"攻击—防守—反击"节奏编排。
