## 1. 完整分镜的"五要素"拆解法

每个分镜格用五要素描述，缺一不可：

1. **动作**（人物动作/情节推进）
2. **运镜**（推拉摇移跟升降旋转环绕，见 lens-language.md）
3. **构图**（对角/对称/居中/仰角/斜线/圆形动线等）
4. **光线**（柔光/冷光/强光/光晕/明暗交错等）
5. **特效**（灵雾/涟漪/气劲/冲击波/光点等）

> 示例（国漫3D法术对决）：`动作：左方修士抬手凝气，率先凝聚法印蓄力 / 运镜：低机位慢推，聚焦手部动作 / 构图：对角站位，气场相互对峙 / 光线：淡柔光笼罩周身 / 特效：指尖萦绕细碎灵雾`

## 2. 漫画分镜表五段式 Prompt（故事→分镜表）

把故事文本转成分镜表的标准指令模板，五段依次输出：

```
一、设定位：你是一名专业漫画分镜师+影视导演，请根据我提供的故事文本，自动拆分为清晰、可视化的分镜表格；

二、提要求：1.严格按照故事情节顺序拆分分镜，不遗漏关键信息；2.每一个分镜必须画面明确、可直接绘制或拍摄；3.分镜颗粒度适中（一个动作或情绪变化即可一个分镜）；4.不扩写剧情，不新增原文不存在的情节；

三、输出格式：Markdown表格，包含列：分镜编号 / 故事片段（对应原文内容）/ 场景（时间/地点/环境）/ 画面描述（人物构图、动作、镜头内容）/ 镜头类型（远景/中景/近景/特写）/ 镜头角度（平视/俯视/仰视/侧面等）/ 情绪与氛围（紧张/压迫/温馨/阴暗等）/ 画面重点（观众第一眼注意的元素）/ 场景图片（根据场景、画面描述、镜头分类、镜头角度、情绪氛围，生成关键的画面）；

四、风格要求：偏向【漫画/动画/分镜脚本】；描述具备画面感，避免抽象词汇；

五、粘贴故事：现在请根据以下故事生成分镜表格：【在这里粘贴故事正文】。
```

## 3. 场景提示词教学模板

以"轻功飞檐追逃竞速戏"为例的教学结构（武侠·动作·竞速）：

**结构**：场景（+类型）→ 画面案例 → 提示词（可直接使用）→ 使用技巧

**可直接使用的提示词**：
```
古代中国风，武侠世界，夜幕/黄昏，两名人物在古代屋顶上轻功飞檐追逐，主角身穿黑色劲装，身姿矫健，飞跃屋檐，长发飘动，动作敏捷；前方逃亡者快速奔跑，在屋顶间跳跃穿梭，紧张刺激的追逃竞速，俯瞰古城夜景/夕阳余晖，灯笼点亮，氛围感强，电影级画面，动态模糊，镜头跟随，高对比度，细节丰富，武侠动作片风格。
```

**使用技巧**：
1. 场景关键词要具体：如夜幕、古城、屋顶、灯笼
2. 动作关键词要明确：如飞跃、跳跃、追逐、奔跑
3. 氛围与风格要到位：如紧张刺激、电影级、动态模糊
4. 可根据需要替换：人物服饰、时间、天气、镜头角度

> 核心理念：**提示词越具体，画面越精彩**

## 4. 16镜完整分镜案例结构（仙侠法术对决）

16镜完整对决的节奏骨架（可套用到双人对决/高潮战斗）：

1-2 蓄力对峙（慢推+横移）→ 3-4 先手进攻 vs 防御（快推+定格）→ 5-6 僵持+变招（俯视旋转+仰拍）→ 7-8 近身对拼（跟随+贴地横移）→ 9-10 击退+再蓄力（后拉+环绕）→ 11-12 高空大招 vs 正面轰击（仰拍上抬+极速推进定格）→ 13-14 硬抗+收招卸力（急拉+环绕舒缓）→ 15-16 对峙+收功（慢推近景+全景拉远）

> 每镜都按五要素（动作/运镜/构图/光线/特效）描述。
