## 1. 镜头运动方向（10种）

| 运镜 | 描述方式（可直接写进分镜/提示词） |
|---|---|
| 推镜头 | 缓慢推进，全景→中景/近景，每秒移动 10–15cm，最终聚焦面部/核心细节 |
| 拉镜头 | 快速拉远，特写瞬间拉至全景，0.5s 内从填满画面切到主体占 10% |
| 水平摇镜头 | 匀速慢摇，从左至右扫过 30m 宽场景，8s 完成，画面边缘保持水平 |
| 垂直摇镜头 | 快速急摇，从地面直摇至天空，2s 完成，捕捉脚到云层的轨迹 |
| 移镜头 | 缓慢侧移，与主体保持 2m 平行移动，每秒 50cm，主体始终居中 |
| 跟镜头 | 匀速跟拍，与主体步行速度（≈1.2m/s）同步，偏差 ≤30cm |
| 升镜头 | 缓慢升空，腰部高度升至 10m 高空，6s 完成，局部展开至全景 |
| 降镜头 | 快速下降，20m 高空直落至主体头顶 1.5m，3s 停稳 |
| 旋转镜头 | 快速旋转，1s 内 360° 光轴翻转（正→倒→正），强化动感冲击 |
| 环绕镜头 | 匀速环绕，以主体为圆心、3m 半径，每秒 30°，12s 一周，始终正对主体 |

## 2. 镜头视角层级（8种）

| 景别 | 功能 |
|---|---|
| 远景 | 主体占比极小，重环境氛围，突出"环境包裹主体" |
| 全景 | 完整呈现主体 + 核心环境，比例平衡 |
| 中景 | 聚焦主要活动区域，兼顾动作细节与局部环境 |
| 近景 | 压缩环境，聚焦局部细节（手势、眼神），强化近距离感 |
| 特写 | 极致聚焦微小局部（眼、手部纹理），排除环境，强视觉冲击 |
| 俯拍 | 自上而下，弱化个体存在感，突出秩序/包围感 |
| 仰拍 | 自下而上，强化向上延伸，传递权威感/力量感/压迫感 |
| 微距 | 超近离拍摄，微观细节放大，背景高度模糊 |

## 3. 情绪化运镜（10种）

每种运镜对应一种情绪动机，写"情绪转折/氛围"镜时使用：

| 运镜 | 情绪传递 |
|---|---|
| 聚焦式推进 | 逐渐沉浸、情绪递进的张力 |
| 抽离式后拉 | 疏离感、释然、时空延展 |
| 探索式横摇 | 追寻、好奇、不安，暗合未知探索节奏 |
| 陪伴式平移 | 无声陪伴、叙事流动感，弱化突兀感 |
| 升华式上升 | 崇高、希望、释然的力量 |
| 压抑式下降 | 压抑、失落、聚焦的沉重感 |
| 迷幻式旋转 | 混乱、迷幻、情绪剧烈波动，强化主观感受 |
| 爆发式急推/急拉 | 突发冲突、紧张爆发，适合情绪转折点 |
| 纪实式手持抖动 | 真实、慌乱、紧张，弱化刻意设计感 |
| 静动转换式 | 平静→涌动、压抑→释放，暗合心理觉醒 |

## 4. 四大焦段

| 焦段 | 作用 |
|---|---|
| 广角 | 视野开阔，交代环境 |
| 标准 | 自然真实，平衡叙事 |
| 中焦 | 突出主体，压缩空间 |
| 长焦 | 虚化背景，强化情绪 |

## 5. 景别切换原则

- **相邻景别不切镜**：远景/全景/中景/近景/特写之间，相邻级直接切换会产生"跳切感"。需要拉开景别层级，或用转场/插入镜头缓冲。
- 景别服务于内容，尤其竖屏更要克制。

## 6. 镜头公式案例（Seedance）

> 东方美学 × 电影镜头：借中式物象框限取景、含蓄叙事。写古风悬疑、诗意氛围镜头时调用。标语：**运镜有逻辑 · 画面有故事**。

### 窥视视角镜（时长 6秒）

```
中式窥视视角镜头，机位隐匿于古宅雕花木隔断后方，透过窗棂镂空花纹向外取景，
画面三分之二被深色木格遮挡分割，仅留窄小视野窥见亭中人物密谈的局部身影，时长6秒
```
- 解析：借中式木窗、屏风等物象框限取景范围，营造隔物窥探观感，天然拉满空间纵深层次，让观众代入暗中观望者视角，生出随时会暴露的紧绷感。适配权谋密会、江湖私谈等悬疑古风桥段。

### 反光倒影视镜（时长 5秒）

```
水面反光倒影镜头，清幽古寺放生池之上，殿宇飞檐与【角色名】身影完整映于池水，
晚风拂过水面漾开层层涟漪，水中倒影随波纹扭曲晃动，镜头全程锁定水面倒影进行拍摄，时长5秒
```
- 解析：依托池水、铜镜等中式反光载体完成含蓄叙事，水中倒影自带虚实相生的意象隐喻，暗含人心两面、世事虚幻的东方意境，既能烘托清冷诗意氛围，也可铺垫暗藏诡谲、心事难测的隐晦情绪。
